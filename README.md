# mirrorfield

镜原 Mirrorfield — 草原上竖立无数面镜子，在镜林中找到对方并开击。子弹会沿镜面反弹。

## 在线游玩

下载 `index.html` 后直接双击打开，或启动任意静态服务器：

```bash
# Python
python -m http.server 8000
# Node
npx serve .
```

然后访问 http://localhost:8000

## 玩法

- **目标**：在镜林中找到红色敌人并击杀，敌人无限复活，坚持更久、拿更多击杀
- **WASD** 移动，**鼠标** 瞄准，**左键 / 空格** 射击
- **P** 暂停，**M** 静音
- 子弹会在镜面上以 45° 反弹（`/` 与 `\` 两种镜面），白色虚线为最多 3 次反弹的预测弹道
- 敌人 AI 会利用镜子进行一次反弹狙击——你同样会被看不见的子弹打死，注意听反弹音效与红色曳光
- 被击中后短暂无敌（闪烁），敌人死亡后于远离你的位置重生
